Windows Guide

The primary platform - everything works out of the box.

← All guides

Standalone executable (recommended)

Grab TWRAR-windows.exe from the Releases page - no Python install needed. Double-click it to launch the GUI directly.

Running from source

git clone https://github.com/TWRAR/Engine.git
cd Engine
pip install -r requirements.txt
playwright install chromium
python gui.py

playwright install chromium is only needed if you don't set browser.executable_path and leave the default browser detection to fall through to Playwright's own bundled Chromium instead of your machine's installed browser.

Default-browser detection

browser.channel: default reads your Windows account's registered default browser (the same setting under Settings → Apps → Default apps) and launches whichever of Brave, Chrome, Edge, or Firefox is set there. Set channel to a specific one of those to force it instead, or give browser.executable_path directly to bypass detection entirely.

Global hotkey permissions

TWRAR no longer uses global system-wide hotkeys (the feature was CLI-only, and the CLI is discontinued as of Engine v3.0.0) - no elevated/Administrator permissions are needed to run it.

Troubleshooting

  • SmartScreen warning on first run - the executable isn't code-signed. Click More info, then Run anyway.
  • Antivirus flags the .exe - a false positive common with PyInstaller-built executables. Verify you downloaded it from the official Releases page, then add an exclusion if needed.
