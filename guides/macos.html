macOS Guide

Fully supported - a couple of Gatekeeper and browser-detection quirks to know about.

← All guides

Standalone app (recommended)

Grab TWRAR-macos.zip from the Releases page, unzip it, and drag TWRAR.app wherever you like - no Python install needed.

Gatekeeper

The app isn't notarized or code-signed, so macOS will refuse to open it with a plain double-click the first time ("TWRAR.app" can't be opened because Apple cannot check it for malicious software"). Either:

  • Right-click (or Control-click) the app → Open, then confirm Open in the dialog that appears - only needed once.
  • Or clear the quarantine flag from a terminal: xattr -d com.apple.quarantine /path/to/TWRAR.app

Running from source

git clone https://github.com/TWRAR/Engine.git
cd Engine
pip install -r requirements.txt
playwright install chromium
python gui.py

Install Python 3.10+ first if you don't have it - Homebrew's brew install python is the easiest route. playwright install chromium is only needed if you don't set browser.executable_path and leave the default browser detection to fall through to Playwright's own bundled Chromium instead of an app in /Applications.

Browser detection

macOS has no OS-level "default browser" registry to read, so browser.channel: default falls straight back to Brave (checked in /Applications), then Playwright's bundled Chromium if Brave isn't installed. Set channel explicitly to brave, chrome, edge, or firefox to launch a specific app in /Applications instead, or give browser.executable_path directly.
