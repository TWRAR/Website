Linux Guide

Fully supported - a couple of Qt system libraries and a chmod to know about.

← All guides

Standalone binary (recommended)

Grab TWRAR-linux from the Releases page, then make it executable and run it:

chmod +x TWRAR-linux
./TWRAR-linux

No Python install needed - it's a self-contained PyInstaller build. There's no desktop entry/launcher shipped; run it directly from a terminal or file manager.

Qt system libraries

PySide6's Qt platform plugin needs a couple of graphics libraries most desktop distros already have, but minimal/server installs and some containers don't. If the GUI fails to start, install them - on Debian/Ubuntu:

sudo apt-get install libegl1 libopengl0

Other distros: look for the equivalent libegl and libopengl (or libgl) packages in your package manager.

Running from source

git clone https://github.com/TWRAR/Engine.git
cd Engine
pip install -r requirements.txt
playwright install chromium
python gui.py

playwright install chromium is only needed if you don't set browser.executable_path and leave the default browser detection to fall through to Playwright's own bundled Chromium instead of a browser already on your system.

Browser detection

Linux has no single OS-level "default browser" registry TWRAR reads, so browser.channel: default falls straight back to Brave (checked at /usr/bin/brave-browser or /usr/bin/brave), then Playwright's bundled Chromium if Brave isn't installed. Set channel explicitly to brave, chrome, edge, or firefox to launch a specific one from its usual /usr/bin/ path instead, or give browser.executable_path directly for a non-standard install location (e.g. a Flatpak or Snap build).

No root required

TWRAR no longer uses global system-wide hotkeys (the feature was CLI-only, and the CLI is discontinued as of Engine v3.0.0), which previously could need elevated permissions or X11 access on some setups. Running the GUI needs no special privileges.
