Steam library artwork

TWRAR ships with a full set of custom Steam library artwork — grid capsules, a hero banner, and a logo — for adding it to your Steam library as a non-Steam game.

Download the artwork (.zip) How to apply it

Portrait grid capsule

600×900 — the tall capsule art shown in Steam's grid view.

Landscape grid capsule

920×430 — the wide capsule art shown in Steam's grid view.

Library hero

3840×1240 — the wide banner shown behind your library page.

Library logo (stacked)

1280×720, transparent — the logo overlay shown on your library hero.

Library logo (horizontal)

1280×720, transparent — icon and wordmark side by side.

Library icon

256×256, transparent — the small icon shown next to your game's name.

Want the exact file sizes and how to apply each one in Steam? See the full guide.
